# Timeline

The timeline module includes the timeline, syntax, and pattern warning tools in one place.

<img class="interface-shot" src="/images/时间轴模块.png" alt="Timeline module">

## Timeline

Drag the timeline to change the preview rendering in real time. Adjust the scale if the playback speed is not comfortable.

## Syntax

Miacode checks your simai syntax and displays a warning when it cannot be correctly parsed by other chart editors, gameplay software, or preview software.

## Pattern warnings

Miacode's pattern warning system is provided by Muri. A warning appears when the chart contains an impossible or potentially impossible pattern.
