# Create a chart

## Create from a song

In the top toolbar, open **File** and choose an audio file to create a chart. Select **File → New**, choose an audio file, and a chart will be created.

## Create by dragging an audio file

You can also drag an audio file into the MiaCode window. This is faster and more convenient, but the chart file will be created directly in the audio file's folder. Move the song to a convenient location before using this method.

Supported audio extensions include `.mp3`, `.wav`, `.flac`, and `.ogg`.
