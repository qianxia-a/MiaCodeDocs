# Edit area

After creating a chart, you can use various tools to adjust and edit it. Common functions are available under **Edit** and **Adjust** in the top toolbar. The following describes Miacode-specific functions.

## Note subdivision adjustment

Select chart objects, then choose **Note subdivision adjustment** from the toolbar or context menu. One step doubles the current subdivision; half a step multiplies it by 1.5.

## Clear all

Delete the selected chart objects while keeping the commas.

## Reset objects

Change the selected chart objects to `1`.

## Normalize the entire chart

Normalize the chart syntax: use one subdivision throughout, insert a line break every measure, and add a space every eight commas.

All of these functions are available from the context menu after selecting chart content.
