# 导出

## 视频导出

MiaCode 支持自定义导出。你可以在导出设置页面对片头、封面、分辨率、帧率、导出方式以及目标文件大小等进行设定。

在默认情况下，导出的各项设定已被提前设定好，可以直接点击开始导出获得谱面确认。导出后的名称为：

`歌曲名称_难度缩写`

例如：

`甩葱歌_MAS`

如果你对当前的效果不满意，例如片头、各类音效等，MiaCode 允许你导入各种自定义素材，以及对导出的效果进行修改，帮助你让你的谱面确认更~~花里胡哨~~。

## 批量导出

当你想要对一张拥有多个难度的谱面进行导出时，就可以使用批量导出一键完成。这里对`输入文件夹`和`输出文件夹`进行解释。

`输入文件夹`：选择想要导出的谱面的文件夹。

`输出文件夹`：选择目标位置，将导出的谱面存入这个文件夹内。

## 区间导出

::: tip
注意！`区间导出`的进度条上的左右滑块缩近下限为15秒距离，但实际最短导出下限为5秒。
:::

MiaCode 支持导出谱面的任意一部分。

这个功能位于 `导出 → 视频导出` 页面下方。你可以使用更加便捷的方式，在谱面编辑页选中想要导出的谱面，右键呼出菜单后点击 `导出所选区间`，MiaCode 会计算开始和结束时间，并自动应用，此时直接点击开始导出即可。

在预览区进度条的左下方位于倍速设置的旁边，你可以看到一个按钮。按下这个按钮后，MiaCode就会进入`区间播放模式`。

在该模式下，可播放的区间取决于你在`区间导出`中设置的区间，这样就可以更清晰的预览你想要导出的区间是否合适。需要退出该模式，只需在该模式下再次点击一下`区间播放模式`按钮即可。

## 封面导出

当 B 站投稿或其他视频平台投稿时没有封面素材？MiaCode 拥有封面导出的功能！它允许你将预设好的精美封面以 `.jpg` 形式导出。你可以在这个功能页面下自由调整，以获取到完美适配 16:9 以及 4:3 的封面图片。

## 打包 ZIP

MiaCode 允许你将当前编辑中的谱面进行 ZIP 打包。在 `导出 → 打包 ZIP` 页面，设定好导出的路径后，就可以将谱面文件夹内的 `maidata.txt`、`track.mp3`、`pv.mp4`、`bg.jpg` 文件进行一键打包并导出到目标路径上。
