# 编辑区

成功创建谱面后，你可以使用各种便利功能调整和编辑谱面。较为常规的功能在这里就不再赘述，你可以在顶部工具栏的“编辑”和“调整”中找到想要的功能。

---

::: tip
下述所有功能都可以选中谱面后右键呼出菜单使用。
:::

## 分音调整

对已经编写的谱面左键选中，在顶部工具栏或右键菜单中可以看到“分音调整”的功能。分音提升/降低，简单来说就是将例如：

```text
{16}1-5[8:1],,,,1,,7-3[8:1],,,,,
```

修改为：

```text
{32}1-5[8:1],,,,,,,,1,,,,7-3[8:1],,,,,,,,7,,,,
```

1 档即是将当前分音乘以 2 倍，半档即是将当前分音乘以 1.5 倍。

## 一键清空

将选中的谱面物件删除，只保留逗号。

## 重置摆件

将选中的谱面物件改为 `1`。

## 整谱规范化

将所有谱面进行规范化语法：整谱统一使用一个分音（在每一行开头都会写出来，哪怕你没写），每隔一个小结换行，每隔 8 个逗号空格。
